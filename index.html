HarshOS — Bare-Metal x86_64 OS

Ongoing
Problem
Wanted to understand what an operating system actually does below the syscall layer, not just how to call one.
Approach
Wrote a freestanding kernel in Rust from boot up: a VGA text-mode driver, an IDT for interrupt handling, a physical memory allocator, a heap allocator, PS/2 keyboard input, a virtual filesystem, and an interactive shell on top.
Result
A bootable OS with real memory management and a usable shell, built without a libc or existing kernel to lean on.
Rustx86_64Systems ProgrammingMemory Management
